## 2. CANS（2610.35530 v1）—— 对 C1 / C6 / C8 / C14 的直接冲击

**其自述的机制**（README，可核）：估计「目标行为梯度」与「共享的整段响应 Fisher 对角」，在能力预算下解出**全体神经元的缩放系数**，
系数**折进 MLP 权重**（推理期零开销）。两个代理分别是：目标 token 的 log-prob（行为）、通用输入上的输出分布 KL（能力）。

### 2.1 它给了「G 该是谁」的第三种答案 —— 而我们的 R7 规则预测了它

我们 §2.16 的结论是：**G 必须匹配你实际施加的约束**。我们用「剂量预算」得到 `G = M`（`ŴŴᵀ` 的 Gram），
并证明了 `JᵀJ` 在剂量预算下会输 26.6%。
CANS 的约束是**能力保持（输出分布 KL）**，而 KL 的局部二次型正是 **Fisher**。所以按我们的规则，它**应该**用 `F`——它确实用了。

⇒ **这是对我们那条原则的一次独立验证**（虽然他们不知道我们的结论）。**判定：C1 记 X（剂量定义不同），但"G 与约束匹配"这一条被增强。**
具体可用：把我们的 `M`、`JᵀJ`、`F` 三者放在同一个坐标集上，按同一个"预算"归一，比较 `u` 的方向差与实测效应——
这正好是我们 R7 的第二次实验，而且 `F` 现在**有外部数据**（见 2.3）。

### 2.2 乘性 vs 加性：一条我们从未写下的前提（新增 C15）

其 `alpha_j` 是**乘性缩放**（把 down_proj 的输入/输出的系数折进权重），其梯度是 `E Σ_t a_{t,j} ∂P/∂a_{t,j}`——
**含激活因子**。我们的加性注入是 `∂P/∂a`。
**乘性增益 ∝ a_{t,j}：当某个神经元原本是沉默的（a≈0），乘性缩放对它无效；加性可以把它打开。**
这解释了一个此前模糊的现象：社区报告的"`L14N8949` 在问候提示上乘性 ×100 仍接近正常，加性立刻改变"——
不是剂量不够，而是**在该提示上它本来就几乎不激活**。
⇒ **判定 W（对"两者可互换"），新增主张 C15。** 我们的输出格式（坐标+符号+**强度**）在加性语义下才有意义。

### 2.3 它发布了 Qwen3-4B 的 Fisher 与目标梯度 —— 这是我们可以直接用的外部数据

仓库里 `cans/artifacts/` 提供「Fisher statistics, target gradients, and example coefficients」。
这给我们两件**以前没有**的东西：
1. 一个**能力代价矩阵**的外部实例（不必自己算 8,800+ 神经元的 Fisher）；
2. 一个可检验的对照：**在我们的坐标上，`M⁺g` 与 `F⁻¹g` 谁在"能力预算"下更优**。

⚠ 前提差：它是 **Qwen3-4B**（不是 3.5-4B）、目标是**毒性/安全**（不是我们的敌意读数）、且是**乘性**。
所以只能做"规则层面的对照"，不能直接搬到我们的模型上当结果。

### 2.4 它自己承认了我们的 C8 边界

其自述：**对角 Fisher 忽略神经元之间的交互**——这正是我们测到的超加性（`6+1=7` 而实测 **16**，2.3×）所指向的东西。
⇒ **判定 W（对 C8）**，而且这段现在可以**作为引用**放进我们的边界条款（此前我们只有自己的数字，没有同行的表述）。

### 2.5 calibration：它报的比我们好，但设定不同

其自述：一阶预测 **R²=0.996 / MAPE 22.0%**；二阶 Fisher 代价 vs 实测 KL **R²=0.922 / MAPE 8.7%**。
我们在 top-K 支撑上是 **0.838–1.010**（realized/predicted），随机支撑上约 **2×** 偏低。
⇒ **判定 S（对 C6），但必须写明**：它的设定是全体神经元的**统一缩放** + 毒性目标；我们是**逐坐标剂量** + log-mass 读数。
真正可学的做法：**把 calibration 变成"随支撑集变化的曲线"**（我们已有两端：随机支撑 2×、top-K 支撑 0.84–1.01），
而不是报一个数。

## 3. RACE（2608.24758 **v2**）—— 对 C2 的测量学帮助

**其机制**（摘要+README，可核）：每个神经元对模块残差更新方向做投影（RDA）→ 每个 token 的带符号证据 →
**Normal-Inverse-Gamma 后验在线累计** → 后验均值给方向与幅度，而 **CAM（Conservative Alignment Magnitude）惩罚不确定估计**。
其自述：**前向统计，算力约为梯度法的百分之一**；且其排序在下游扰动上"更 domain-specific"。

**对我们的用处（判定 S）**：我们的 G1/G2 现在是**点估计 + 分半重测**（逐上下文 r 中位 0.4722，池化才到 0.5469）。
RACE 提供的是**同一个思想的廉价版**：给每个坐标一个**不确定度**，然后**按置信下界排序**。
这对我们有三个具体含义：

1. **排序规则可以从"最大 |g|"改成"最大下界"**——这在本机上几乎免费（我们的 g 本来就逐上下文算过，只要加一个跨上下文的后验/自助下界）。
2. 它**不能**替代我们的 `τ→J`：RDA 的对象是"该神经元对模块自身更新的参与度"，**不是**"对某个语义目标的贡献"。
   ⇒ 判定上必须区分（这也是我在 ledger 里给 C4 记 X 的原因）。
3. 它的 CAM 提醒我们一件我们做过但没形式化的事：**§2.20 的 top-1 只拿 17.3%，而 top-K 曲线近对数**——
   如果按"下界"排序，K 的合适取值可能比 256 更小。**这是一个便宜的可检验预测**（见 §6.2）。

## 4. Transcoders（2610.24521 v1）—— 对 C13 输出形式的理论支持

摘要级结论：**"neuron features"**（权重与单个 MLP 神经元强对齐的 transcoder 特征）在**晚期层占活跃特征的相当比例**；
只有它们是**跨训练 run 稳定**的、"与底层 MLP 的 Jacobian 一致"的、且相对随机初始化变化更大的；
其余特征会漂移。

**对我们的用处（判定 X，偏 S）**：这独立支持我们"**输出 = 残差方向 + 最简代表 + 等价类**"而不是"一份唯一特征名单"——
因为我们早就知道单坐标不唯一（`{u : Ŵᵀu = d}` 维数 **6656/层**），而它从**特征基**那一侧得到同一结论：
**换一个基，只有与神经元对齐的那部分稳定**。
⇒ 可以写进 C13 的表述：**坐标的"稳定性"来自它与 MLP 的对齐，而不是来自任何一种特征字典**。

## 5. Steering Geometry（2609.06289 v1，EMNLP 2026）—— 对 C4 的**设计**帮助（不是证据）

其做法：用 **Schwartz 20 值圆周**与 **MFT 6 基础**的结构去检验 steering 方向，
即"**相容的值应被增强、相反的值应被抑制、且存在跨值迁移**"，并横评 7 种方法（CAA/SAS/Spherical/ODESteer/OPT/COLD-Steer/BiPO）。
其摘要明确：**既有工作多在孤立行为上验证 steering，因此不清楚方向是否编码连贯语义结构，还是只利用了行为特异性的捷径**。

**对我们的用处（判定 X，但提供了 R2c 的设计模板）**：
我们的特异性检验缺的正是"**一个有预期关系的多特质结构**"。BFFM-100 给我们 10 个同语域池（`II± / I± / III± / IV± / V±`），
但 Big-Five **不是**一个带"相容/相反"预测的圆周结构。而 Schwartz 20 值**是**：
相邻值相容、对角值相反。⇒ **我们可以借它的设计**：把"敌意 vs 其余九池"改成"**沿一个理论结构的两端**"，
这比我们原来的 C1 判据（`II−` 对 `I−/III−/IV−/V−`）更容易有明确预测。

⚠ 但注意：这仍是 **X**，不是 S——Schwartz 值是**社会/道德**维度，不是"评价性人物描述词"的同语域特质，
而且它的结局是行为评测，不是我们的 J2 读数。

## 6. 由这四篇导出的**三条可执行动作**（按成本排序）

### 6.1 最便宜：把 `M` 与 `F` 放在同一坐标集上比方向（~30 分钟 GPU）
用 CANS 的 artifacts 或自己算 `F`（对角，一次前向+反向即可估），在**我们的 32 坐标**上算
`cos(u_M, u_F)`、`cos(d_M, d_F)`，以及各自在"能力预算"下的预测值。
**可检验的预测**（写在这里，跑之前）：因为 `F` 是输出分布的二阶量而 `M` 是残差位移的二阶量，
二者的比应**显著偏离 1**（我们已知 `cos(u_g, u_M) = 0.56–0.60`，若 `cos(u_M,u_F)` 也 <0.8，说明"约束决定方向"这条被第三次验证）。

### 6.2 次便宜：把排序从"最大 |g|"改成"**置信下界**"（CPU 即可，我们的数据已在仓里）
我们每个上下文都有 g。用 8 个上下文的经验自助（bootstrap）给每个坐标一个下界，重排 top-K 曲线。
**可检验的预测**：按 5% 下界排序时，达到 73% 捕获率所需的 K 会**小于** 256（因为 §2.20 的曲线上许多坐标的贡献在上界与下界之间波动）。
这条不需要 GPU，先做，就能判断 RACE 的 CAM 对我们**有没有用**。

### 6.3 不便宜但必要：把特异性从"多池比较"升级成"**带结构的多特质检验**"（借 §5 的设计）
前提仍是先修混合长度读数路径（`R2c` 的阻塞），再按"相容/相反"的预期关系设计判据。
